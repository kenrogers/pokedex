# Security

If you find a security issue in DEX Open, please do not open a public GitHub issue or post the details in public.

Use GitHub's private vulnerability reporting on this repository: open the **Security** tab and choose **Report a vulnerability**. If that option is not enabled yet, please do not file a public issue; wait until private reporting is available, or contact the maintainer privately.

Include enough detail to reproduce the issue, and give us time to fix it before any public disclosure.
